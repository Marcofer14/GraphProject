# v0.2.0 · Attention + POMO models (phase 2)

First trained neural solvers. Attach `tsp20_pomo.pt`, `cvrp20_pomo.pt`, `cvrp50_pomo.pt` and
`cvrp100_pomo.pt`
from `checkpoints/` as release assets; `scripts/download_models.py` fetches them by name.

| Model | Problem | Training | Val length (1,000 inst.) | Benchmark gap vs PyVRP | Latency |
|---|---|---|---|---|---|
| `tsp20_pomo.pt` | TSP, 20 customers + depot | 30 epochs · ~35 min · GTX 1660 Super | 3.9611 | 0.23 % | 80 ms |
| `cvrp20_pomo.pt` | CVRP, 20 customers, capacity 30 | 30 epochs · ~40 min | 6.2284 | 0.67 % | 80 ms |
| `cvrp50_pomo.pt` | CVRP, 50 customers, capacity 40 | 60 epochs (best 52) · ~2.3 h | 10.6492 | 1.81 % | 190 ms |
| `cvrp100_pomo.pt` | CVRP, 100 customers, capacity 50 | 56 epochs (best 55) · ~3.5 h | 16.3496 | 3.53 % (1.34 % + LS) | 650 ms |

All three: 6-layer Transformer encoder, 128-dim, 8 heads, instance norm, POMO shared baseline,
1.30 M parameters, ~5 MB. Inference uses POMO multi-start greedy decoding with x8 augmentation.

**Use**

```bash
uv run python scripts/download_models.py
uv run nr-bench-synth --problem cvrp --size 50 --configs pyvrp:10 attention
```

Trained on uniform synthetic instances (Kool et al. distribution). They do not handle time
windows or real road matrices yet (phases 3–4) and degrade on sizes far from training.
