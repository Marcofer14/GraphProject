# v0.3.0 · Amazon-calibrated models (phase 3)

Models trained on the generator calibrated on 6,112 real Amazon routes (ADR-011), with
customer-centric normalisation and a polar depot encoding (ADR-012). Attach the `.pt` files from
`checkpoints/` as release assets.

| Model | Trained | Real-route result (200 unseen routes, + local search) |
|---|---|---|
| `cvrp100_pomo_amazon.pt` | curriculum stage from the 50-stop model, 25 epochs | **4.32 % controllable gap, 0.9 s** — reference model |
| `cvrp150_pomo_amazon.pt` | curriculum stage from the 100-stop model, 12 epochs | 5.88 % |
| `cvrp50_pomo_amazon.pt` | 32 epochs on Amazon-like CVRP-50 | 5.96 % |
| `cvrptw50_pomo_amazon.pt` | time-aware, windows at 25 % width (ADR-014/015) | 11.29 % |

For comparison on the same routes: PyVRP (10 s) 0.36 %, OR-Tools (10 s) 4.98 %, real drivers
22.2 %. All models: 6-layer Transformer, 128-dim, instance norm, POMO, 1.30 M parameters, ~5 MB.

```bash
uv run nr-bench --mode route --split evaluation --n 200 \
    --configs reference pyvrp:10 attention_ls@checkpoints/cvrp100_pomo_amazon.pt
```
